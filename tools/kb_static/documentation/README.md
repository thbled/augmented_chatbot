# Base documentaire thématique

Déposez ici des documents Markdown (`.md`) sur les sujets traités pendant l'événement :
fiches techniques, glossaires, synthèses, particularités d'une technologie, etc.
Ils sont copiés tels quels dans la base de connaissances par `conference-tools build-kb`
(ce fichier README est ignoré).

Conseils de rédaction pour une bonne recherche par le LLM :

- un sujet par fichier, un titre `#` explicite (ex. `# RAG : principes et limites`) ;
- des sections `##` courtes et autonomes (chaque section doit se comprendre seule) ;
- mentionner les sessions ou speakers liés au sujet par leur nom exact ;
- éviter les tableaux très larges et les images (non exploitées).
